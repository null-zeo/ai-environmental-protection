# 🌍 IA para Proteção do Meio Ambiente

Um site interativo com fluxograma que demonstra como a Inteligência Artificial pode ajudar o ser humano a proteger o meio ambiente.

## 📋 Características

- **Fluxograma Interativo**: Visualização dinâmica de como a IA se conecta com diferentes áreas de proteção ambiental
- **Informações Detalhadas**: Clique nos nós do fluxograma para ver descrições de cada aplicação
- **Design Responsivo**: Funciona perfeitamente em desktop, tablet e celular
- **Aplicações Práticas**: Exemplos reais de uso de IA em conservação ambiental

## 🚀 Como Executar

### Pré-requisitos
- Python 3.7+
- pip (gerenciador de pacotes Python)

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/null-zeo/ai-environmental-protection.git
cd ai-environmental-protection
```

2. Instale as dependências:
```bash
pip install -r requirements.txt
```

3. Execute a aplicação:
```bash
python app.py
```

4. Abra seu navegador e acesse:
```
http://localhost:5000
```

## 📊 Fluxograma Principal

O fluxograma mostra o fluxo de como a IA ajuda na proteção ambiental:

```
                    Inteligência Artificial
                              |
                ______________|______________
               |      |       |      |       |
         Monitor  Otimizar  Gestão  Agri.   Reduzir
         Ambient  Energia   Água    Sust.   Poluição
               |      |       |      |       |
               |------|-------|------|-------|
                              |
                   Proteção do Meio Ambiente
```

## 🎯 Aplicações de IA Destacadas

1. **Monitoramento Ambiental** - Satélites e sensores com IA
2. **Detecção de Desmatamento** - Análise automática de imagens
3. **Previsão Climática** - Modelos de Machine Learning
4. **Conservação de Biodiversidade** - Rastreamento de espécies
5. **Otimização de Energia** - Redes inteligentes
6. **Gestão de Recursos Hídricos** - Detecção de vazamentos
7. **Agricultura Sustentável** - Precisão agrícola
8. **Redução de Poluição** - Monitoramento de qualidade

## 🛠️ Tecnologias Utilizadas

- **Backend**: Flask (Python)
- **Frontend**: HTML5, CSS3, JavaScript
- **Visualização**: vis.js (biblioteca para grafos)
- **Design**: CSS Grid, Flexbox, Gradientes

## 💡 Como Usar o Fluxograma

1. **Visualizar**: O fluxograma é exibido automaticamente ao carregar a página
2. **Interagir**: Clique em qualquer nó (caixa) para ver mais detalhes
3. **Navegar**: Use o mouse para arrastar, zoom com a roda do mouse
4. **Explorar**: Passe o mouse sobre os nós para destacá-los
